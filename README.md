# 🛒 MERN Stack E-Commerce Website

A full-stack e-commerce web application developed using the MERN stack (MongoDB, Express.js, React.js, and Node.js). The project includes a customer-facing shopping website, an admin panel for managing products and orders, and a backend API to handle application functionality.

## 🚀 Features

### 🛍️ Customer Frontend
- Responsive and user-friendly interface
- Browse and explore products
- Product collection and category pages
- Product details page
- Shopping cart functionality
- Update product quantities and remove items
- User login and registration
- Place orders and view order history
- Order verification

### ⚙️ Admin Panel
- Admin authentication
- Add new products
- Upload product images
- Manage product listings
- Manage customer orders
- View and update order information

### 🔧 Backend
- RESTful API development using Node.js and Express.js
- MongoDB database integration
- User and admin authentication
- Product management APIs
- Cart and order management
- Image uploads using Multer
- Cloudinary integration for image storage
- Payment gateway integration

### 💳 Payment Integration
- Stripe payment integration
- Razorpay payment integration
- Payment verification functionality

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/arpana23/mern_ecommerce.git
```

### 2. Navigate to the Project Directory

```bash
cd mern_ecommerce
```

### 3. Install Dependencies

Install dependencies separately inside the frontend, admin, and backend directories.

```bash
cd frontend
npm install

cd ../admin
npm install

cd ../backend
npm install
```

### 4. Environment Variables

Configure the required environment variables for:

- MongoDB connection
- JWT authentication
- Cloudinary credentials
- Stripe API keys
- Razorpay API keys

### 5. Run the Application

Start the backend, frontend, and admin applications using their respective development scripts.

```bash
npm run dev
```

Run the command from each application directory where the development script is configured.
